# bigliettini

Bigliettini con la Parola di Dio per le Evangelizzazioni.

- `Bigliettini.pdf` — i bigliettini da stampare.
- `versetto/` — pagina che mostra un versetto ispirazionale casuale in italiano (CEI 2008), scelto fra 960 passi incorporati nella pagina (nessuna API a runtime). Pensata per essere aperta da un tag NFC:
  `https://alessandroargentieri.github.io/bigliettini/versetto/`

## Fonti

- Testo: Sacra Bibbia CEI 2008 © Conferenza Episcopale Italiana, da [lachiesa.it](https://www.lachiesa.it/bibbia/); versetti isolati riportati per solo uso personale e di evangelizzazione.
- Selezione dei versetti: temi positivi dei dati di [OpenBible.info](https://www.openbible.info/topics/) (licenza CC-BY), con i riferimenti convertiti nella numerazione CEI.
