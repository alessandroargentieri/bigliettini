# bigliettini

Bigliettini con la Parola di Dio per le Evangelizzazioni.

- `Bigliettini.pdf` — i bigliettini da stampare.
- `versetto/` — pagina che mostra un versetto casuale in italiano (CEI 2008, via [BibleGet I/O](https://www.bibleget.io)). Pensata per essere aperta da un tag NFC:
  `https://alessandroargentieri.github.io/bigliettini/versetto/`
